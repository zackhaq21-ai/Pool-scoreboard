# Pool Night Scoreboard

A standalone, offline pool-night scoreboard. Open the HTML file in any browser —
no server, no install, no internet needed. Scores save on that device.

## Files

- **`pool-night-scoreboard.html`** — the loaded board, with the Night 1 scores,
  teams, and history baked in. Record a winner, standings and rotation update,
  and the next team comes up automatically.
- **`pool-night-scoreboard-blank.html`** — a blank board to start a fresh night.
  Starts with Usif, Zack, and Rayann at 0–0; add players and build teams from
  the Players panel.

## How a night works

- **One game per match.** Tap the winner, the winner stays on, the loser goes
  to the back of the queue, and the next team comes up automatically.
- **Modes:** Teams, 1v1 Solo, Cutthroat (ball groups 1–5 / 6–10 / 11–15), and
  King of the Hill.
- **Rotation is locked** so nobody gets skipped — Change teams is the only
  manual override.
- **TV mode** has a big pause button (Space or P) and auto-rotates views.
- **1v1 Tournament** with single or double elimination, race-to targets,
  and a champion screen.
- **Undo / redo**, searchable game log, backup export/restore.

## Offline games

Games recorded in these files are tagged OFFLINE. Export them from the More
tab (Export offline games only) to merge them back into the main board.
